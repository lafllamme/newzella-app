## Arbeitsrichtung

Die neue Oberfläche soll modern, warm, hochwertig und deutlich bakery-spezifisch wirken. Formen, Karten, Buttons und Bildmasken werden grundsätzlich rund oder organisch. Die Typografie wird in einem visuellen Board getestet: eine charaktervolle Schnörkel-/Script-Schrift für Headlines plus eine ruhige, professionelle Schrift für Navigation, Text und CTAs.
